# Анализ данных о Pokémon

Домашнее задание с онлайн курса Т-Образования - https://education.tbank.ru/school/basic/analysis/

Небольшой разбор датасета с характеристиками Pokémon.
Стек: Python, pandas, Matplotlib, Seaborn и Jupyter
Суть проекта — посмотреть распределение типов, сравнить легендарных и обычных Pokémon и собрать несколько простых таблиц по силе персонажей.
